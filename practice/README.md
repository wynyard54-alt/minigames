# 연습판 (혼자 AI와 하기)

`practice.html`은 Claude 아티팩트로 공개한 연습판의 원본입니다 (https://claude.ai/artifact/1TfmM4ZcfJSgUxLgUHymK9).

- 서버 없이 브라우저 혼자 돌아갑니다. `<script>` 안에 `game.js`의 엔진 부분(`const GameEngine = {` 앞까지)을 그대로 붙여 넣었습니다.
- **`game.js` 규칙을 바꾸면** 이 파일의 엔진 부분도 같이 바꿔야 연습판에 반영됩니다.
- 아티팩트 형식이라 `<!doctype html><html><head>` 없이 `<title>`과 `<style>`부터 시작합니다. 그냥 브라우저로 열어 볼 때는 앞에 `<!doctype html><meta charset="utf-8">`를 붙이면 됩니다.
- 아직 효과음은 없습니다.
