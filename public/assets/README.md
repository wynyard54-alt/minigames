# 게임 그림

- `arena.webp`: 벽·부시용 투명 이미지, 768×512, 40,778바이트. 예전 캐릭터 영역은 사용하지 않습니다.
- `fighters.webp`: 승인한 네 방향 캐릭터 × 빨강·파랑 팀, 768×384, 52,950바이트. 윗줄 빨강, 아랫줄 파랑이며 각 줄은 오른쪽·왼쪽·뒤·앞 순서입니다. 걷기 프레임은 없습니다.
- 합계 93,728바이트(약 94KB). 이미지 생성 도구로 제작하고 WebP로 축소·압축했습니다.
- `public/render.js`의 `SPRITES`, `FIGHTERS`에 그림 위치를 정의합니다. `FIGHTERS` 좌표는 1024×512 기준이고 실제 읽을 때 0.75배로 변환합니다.
- 그림별 높이와 몸 중심·발밑을 맞추며 전체 그림을 회전하지 않습니다. 수평에서 65도 이상이면 앞·뒤로 전환하고, 55도 미만이면 옆모습으로 복귀하여 경계에서 깜빡이지 않게 합니다.
- 서버 이동·발사 방향은 연속된 실제 방향을 그대로 사용합니다. 네 방향 구분은 외형에만 적용합니다. 그림 안의 총 각도는 네 방향으로 제한됩니다.
- 외부 이미지 서버나 CDN 없이 교실 서버에서 각각 한 번 불러옵니다. 이미지별 로딩 전이나 실패 시 기존 도형을 사용합니다.
- 벽·부시는 판정 영역 안에 타일로 그리고 고정 맵을 캔버스에 미리 그려 재사용합니다. 팀색 받침, 내 캐릭터 테두리, 체력·탄창·숨기·회복·보호막 표시를 유지합니다.
- 독립 실행 연습판(`practice/practice.html`)은 별도 원본이므로 이번 그림 적용 대상에 포함하지 않았습니다.

## 배틀 아레나 적

- `arena-enemies.webp`: 작은 적·장갑 적·선물 적 3종, 384×128, 12,896바이트. 방향 구분이나 걷기 프레임 없이 정지 그림을 재사용합니다.
- `public/arena.js`에서 로딩 시 일반/피격 이미지를 64×64 캔버스에 각각 한 번 준비합니다. 매 프레임 이미지 색상 필터나 그림자 흐림을 계산하지 않습니다. 로딩 실패 시 기존 도형으로 표시합니다.
- 동시 효과 최대 36개, 떠오르는 글자 최대 10개. 다중 처치 시 일반 점수 글자를 생략해도 실제 점수·처치·아이템 계산은 유지합니다.
- 아이템 표시 갱신은 초당 최대 10회, 효과 색상·남은 초·막대로 표시합니다. 적 속도·체력·출현·아이템 확률과 지속 시간은 변경하지 않았습니다.
