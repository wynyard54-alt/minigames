# 게임 그림

`arena.webp`는 시안에서 만든 빨강·파랑 캐릭터, 돌벽, 부시를 모은 투명 이미지입니다.
- 크기: 768×512, 40,778바이트(약 41KB). 이미지 생성 도구로 제작하고 WebP로 축소·압축했습니다.
- `public/render.js`의 `SPRITES`에 각 그림의 위치를 정의합니다. 이미지를 교체할 때 좌표도 함께 확인하세요.
- 외부 이미지 서버나 CDN 없이 교실 서버에서 한 번 불러옵니다. 로딩 전이나 실패 시 기존 도형을 사용합니다.
- 벽·부시는 실제 판정 영역 안에 타일로 그리며, 고정된 맵을 캔버스에 미리 그려 매 프레임 재사용합니다.
- 캐릭터는 이동 방향에 따라 회전합니다. 팀색 받침, 내 캐릭터 테두리, 체력·탄창·숨기·회복·보호막 표시를 유지합니다.
- 독립 실행 연습판(`practice/practice.html`)은 별도 원본이므로 이번 이미지 적용 대상에 포함하지 않았습니다.
