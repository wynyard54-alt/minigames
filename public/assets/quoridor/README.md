# 쿼리도 그림
- `board.webp`: 사용자 선택 귀여운 시안에서 말을 제거한1254×1254 배경. 칸81개/모서리 모두 표시.
- `pawns.webp`: 조사병단 남/여, 전사대 남/여2×2 투명 원본 시트. `sprites.json` 영역으로 그려 물리적 높이 통일, 받침 중심을 칸 중앙에 정렬.
- `wall-h.webp`, `wall-v.webp`: 낮은 가로/세로 돌벽, 세로 끝단 한 단 높은 수정본. 소스 영역과 표시 크기는 별개이며 게임상 두칸 길이/낮은 높이로 렌더.
- `thumbnail.webp`: 첫 화면용 축소 배경. 게임 실행 그림합계 약650KB.

- `victory-banners.webp`: 승리창용 만화풍 녹색 날개/붉은 방패 깃발 2종 시트(약28KB). 사실적 천/금속 시안은 사용자 요청으로 사용하지 않음. 기존 말과 맞춰 굵은 윤곽선·단순 명암으로 새로 생성.
