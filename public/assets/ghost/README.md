# 고스트헌터 그림 자료

사용자와 Codex가 대화에서 준비한 원본을 게임용 WebP로 축소·분할한 자료입니다. 외부 이미지 서버나 폰트 요청 없이 로컬에서 제공합니다. 전체 그림 약 1.8MB.

- `map.webp`: 사용자가 승인한 10지역 지도. `public/ghost-data.js`에서 이 그림(1254×1254)의 복도35칸과 문을 직접 측정해 실제 이동에 사용합니다. 이동 가능한 칸과 지역 번호만 강조하며 점선과 추가 이름표는 표시하지 않습니다.
- `{green,red,blue,orange,yellow,purple}-{단계}.webp`: 트레이너+파트너 17종. 주황은 0~1, 나머지는 0~2. 빨강 중간 진화는 사용자가 제공한 파이숭이 그림을 다듬은 자료입니다.
- `card-0.webp`~`card-29.webp`: 지역 번호당 3장. `card-30.webp`: 다시 섞기.
- `mob-*.webp`, `mobs.json`: 출현 포켓몬 21종. 기존 3×2 또는 3×1 시트를 나눈 자료. 앞서 보라색 아우라 작업이 완료된 15종은 해당 판을 사용하고, 나머지 6종은 기존 판을 사용합니다.
- `darkrai.webp`: 지역 위에 겹쳐 표시하는 다크라이.
- `seal-1.webp`~`seal-8.webp`, `seal-back.webp`: 봉인조각 앞면과 공통 뒷면.
- `card-back.webp`: 공통 카드 뒷면(아직 출현 카드가 없을 때 지도 아래 카드 자리에 표시).

지도 위 봉인조각은 지역명 오른쪽에17~30px의 색면 SVG 보석으로 표시하며, 기존 큰 봉인조각 원본은 자료로 보관합니다. 플레이어 말 옆에 운반 조각 번호를 표시합니다. 지도에 그려진 지역 이름을 그대로 사용하며, 정확한 출현 카드 이름은 카드 옆 텍스트에서도 확인할 수 있습니다.

- `card-31.webp`: 창공날기, `card-32.webp`: 초승달의 축복(사용자 승인 원본을 축소, 약90KB 합계).
- 말 원본은 유지, `ghost-data.js`의 `pawnBounds`로 투명 여백 보정.
